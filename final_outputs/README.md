# Final outputs

Results behind the paper. Only aggregate metrics, keyword tables, reports and figures are
tracked; files containing Reddit text or per-post IDs stay local (see the root `.gitignore`).

| Folder | What it contains | Produced by |
|---|---|---|
| `posts_merge/` | De-duplication counts and corpus statistics (71,873 → 70,425 posts) | corpus consolidation step |
| `posts_benchmark/` | Per-model BERTopic metrics, coherence (c_v, c_npmi), topic keywords, benchmark report | `scripts/posts/run_posts_bertopic.py`, `run_posts_coherence.py` |
| `posts_retrieval/` | 25-query retrieval evaluation (P@10, MAP, MRR, nDCG@10) per model | `scripts/posts/run_posts_retrieval.py` |
| `benchmark_figures/` | Embedding-benchmark figures (paper Fig. 3 = `fig_posts_benchmark_compact`) | `scripts/posts/generate_posts_figures.py`, `scripts/figures/make_revised_figures.py` |
| `topic_modeling/` | 30-config hyperparameter search, final 41-topic model, refinement summary | `src/pipeline/bertopic_search.py`, `bertopic_finalize.py`, `bertopic_refinement.py` (audit) |
| `paper_assets/` | Paper figures (fig01–fig16 + revised figures), tables, taxonomy, metadata, reports | `src/pipeline/paper_assets.py`, `paper_extras.py`, `paper_tables.py`, `scripts/figures/*` |
| `comments_benchmark/` | 5-model benchmark on the comment corpus | `scripts/comments/run_comments_analysis.sh` |
| `comments_analysis/` | Interaction taxonomy, cross-corpus response analysis, suicidal-post statistics, Fig. 6 | `src/analysis/comments_taxonomy_v2.py`, `scripts/comments/*`, `scripts/figures/make_cross_corpus_fig.py` |
| `annotation_validation/` | Human-annotation agreement, confusion matrices, classification reports | `annotation_summary.csv`: `scripts/annotation/annotation_agreement.py`; other reports: original validation run |

## Folder renames

Earlier versions of the scripts wrote to `outputs/`. The mapping is:
`outputs/final` → `topic_modeling`, `outputs/final_paper` → `paper_assets`,
`outputs/figures_publication` → `benchmark_figures`, `outputs/comments_analysis_v2` → `comments_analysis`;
all other folder names are unchanged. Some generated reports inside these folders still mention
the old `outputs/...` paths.
